# Sales Data Analytics 📊

A beginner-friendly project exploring the analytics process of turning raw sales data into business insights using Python.

Part of my Microsoft Learn journey focused on data analysis and business reporting.

## Project Overview
This project follows the analytics workflow:
1. Data collection
2. Data cleaning
3. Exploratory data analysis
4. Business insights and recommendations

## Files in this repository
- `sales_data.csv` – sample sales dataset
- `analysis.py` – Python script for basic sales analysis
- `README.md` – project documentation

## Setup

Create a virtual environment and install dependencies:

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Run the analysis:

```bash
python analysis.py
```
