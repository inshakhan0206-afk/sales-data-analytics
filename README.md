# Sales Data Analytics 📊

A beginner-friendly project exploring the analytics process - turning raw sales data into business insights using Python.

Part of my Microsoft Learn journey - "Explore the analytics process that turns data into insights"

## 📌 Project Overview
This project follows the complete analytics lifecycle:
1.  Data Collection
2.  Data Cleaning
3.  Exploratory Data Analysis (EDA)
4.  Insights & Business Recommendations

## 🛠️ Tools Used
- Python
- Pandas
- Matplotlib / Seaborn

## 📈 Key Insights (Sample)
- Top selling products
- Monthly sales trend
- Region-wise performance
